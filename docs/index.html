cc-status

a terminal HUD for Claude Code

Real-time session telemetry at the bottom of your terminal: context, cost, tools, agents, and focus.

Install View on GitHub
claude — cc-status

01

What you get

Session

Repo + branch, model, duration, diff stats, context bar, and token counts in one scan.

Cost

Cost, burn rate, tokens/min, API ratio, cache efficiency, and config counts.

Soul

cc-soul health snapshot: nodes, triplets, and confidence.

Tools

Running tools plus completed counts from the transcript.

Agents

Subagent activity with running/completed status.

Todos

Current in-progress task so you don't lose focus mid-flow.

02

Why it matters

>

Know when you're about to hit context limits before it hurts answer quality.

>

See cost and burn rate live, not after the session.

>

Spot slow sessions by separating API time from everything else.

>

Keep a mental map of tools, agents, and tasks without leaving the terminal.

03

Installation

terminal 
$ git clone https://github.com/genomewalker/cc-status
$ cd cc-status && npm install && npm run build

Wire it to Claude Code's statusLine config and it appears at the bottom of your terminal. Zero dependencies beyond Node.js.

04

Data sources

  • // Reads Claude Code's statusLine JSON on stdin.
  • // Uses session-level telemetry: cost, duration, context usage, cache reads.
  • // Computes display-friendly metrics: burn rate, tokens/min, ratios.
  • // No external services. No network calls. Local only.
05

FAQ

Does it phone home?
No. It reads stdin and local files only.
Will it work outside Claude Code?
Not really — it's built for statusLine stdin.
Can I trust the cost numbers?
They come from Claude Code's session telemetry; cc-status just formats and derives rates.
What if I don't run cc-soul?
That line stays quiet; everything else still works.
